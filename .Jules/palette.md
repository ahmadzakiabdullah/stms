## 2024-05-24 - Screen Reader Friendly Close Buttons in Radix Dialog/Sheet
**Learning:** Radix UI's `DialogPrimitive.Close` components inside Shadcn's generic `DialogContent` and `SheetContent` wrap a `Button` with a child `<span className="sr-only">Close</span>`. These buttons don't have an `aria-label` which means screen readers fall back to reading the visually hidden text inside. It's best practice to give icon buttons an explicit `aria-label` attribute if they only contain an icon (and perhaps a visually hidden text fallback), or just rely on the `aria-label` to replace the visually hidden text entirely, as sometimes wrapping things can cause redundant announcements. However, since the text `Close` is inside `<span className="sr-only">`, it's announced. But adding an `aria-label="Close"` directly to the `<Button>` or `<SheetPrimitive.Close>` ensures standard screen reader announcements. Actually, looking at `resources/js/components/ui/dialog.jsx` and `sheet.jsx`, there are `<span className="sr-only">Close</span>` tags, which is sufficient for screen readers, but adding `aria-label="Close"` directly or using `t('Close')` if translation is available might be better? Wait, the rule says: "When enhancing accessibility, do not add `aria-label` attributes to buttons or components that already contain visually hidden text (e.g., `<span className="sr-only">Close</span>`), as this creates redundant announcements for screen readers."

**Action:** Don't add aria-label if there's an sr-only span.
