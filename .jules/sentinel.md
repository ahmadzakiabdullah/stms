## 2025-08-06 - Missing Rate Limiting on Password Reset\n**Vulnerability:** The password reset endpoint did not have rate limiting, allowing attackers to spam the endpoint and potentially enumerate user emails.\n**Learning:** Always explicitly add `throttle` middleware to sensitive endpoints, especially those that trigger external actions like sending emails.\n**Prevention:** Ensure `throttle:6,1` (or similar) is applied to routes handling password resets, logins, and other sensitive actions.
