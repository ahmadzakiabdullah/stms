## 2024-03-24 - Accessibility for Inertia Link wrapped with UI Button
**Learning:** In Inertia + shadcn/UI apps, it's common to wrap `<Link>` in UI components like `<Button>` to reuse button styles. If done incorrectly as `<Link><Button/></Link>`, it creates invalid HTML (`<button>` inside `<a>`) which confuses screen readers. Furthermore, anchor elements (`<a>` generated by `<Link>`) do not natively support the `disabled` attribute, which means visually disabled buttons still receive keyboard focus.
**Action:** Always use the `asChild` prop on the UI component (e.g. `<Button asChild>`) to forward the button styles to the inner `<Link>` element. When the button should be disabled, you must manually apply `aria-disabled={true}` and `tabIndex={-1}` on the inner `<Link>` element to remove it from the keyboard tab order and properly announce its disabled state to screen readers.
