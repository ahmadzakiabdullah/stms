## 2025-08-03 - Accessible Pagination and Nested Interactive Elements
**Learning:** Found nested interactive elements (e.g., `<a>` wrapping `<button>`) in the Pagination component, which is invalid HTML and causes screen reader confusion. Also learned the importance of wrapping pagination in a `<nav aria-label="Pagination">` and using `aria-current="page"` to indicate the active page for accessibility.
**Action:** When creating or modifying UI components that act as links, ensure they use the `asChild` pattern (provided by Radix UI/shadcn) so that the interactive element becomes the `<a>` tag directly. Always wrap pagination structures in appropriate landmark navigation (`<nav>`) and explicitly set `aria-current="page"` and `aria-label` for links to improve screen reader experience.
